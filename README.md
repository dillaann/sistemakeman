# SISTEMA SERRALHERIA KEMAN

Aja como um especialista em Recuperação de Vendas e UX Design. Preciso criar uma LANDING PAGE DE REMARKETING focada em pessoas que visitaram meu site, quase compraram, mas desistiram.

O OBJETIVO: Oferecer um DESCONTO FINAL IRRECUSÁVEL (Downsell) para fechar a venda agora.

1. ESTILO VISUAL (URGÊNCIA SÉRIA):

Fundo: Branco (#FFFFFF) ou Cinza Muito Claro (#F3F4F6). Nada de cores fortes no fundo.

Barra de Topo: Vermelho Alerta (#DC2626) com texto branco.

Botões: Verde Neon (#16A34A) com animação de pulso.

Estilo: Deve parecer uma página de 'Status do Pedido' ou 'Aviso de Pendência'. Limpa e direta.

2. ESTRUTURA E TEXTOS (COPYWRITING):

BARRA DE TOPO (STICKY):

Texto: '⚠️ ATENÇÃO: SEU ACESSO ESTÁ PENDENTE. FINALIZE AGORA PARA NÃO PERDER A VAGA.'

HEADLINE (H1 - O Gancho):

Texto: 'FOI POR CAUSA DO PREÇO? AQUI ESTÁ UM DESCONTO ÚNICO PARA VOCÊ COMEÇAR.'

SUBHEADLINE (H2):

Texto: 'Vi que você quase entrou para o Desafio do Mounjaro Natural, mas acabou deixando para depois. Eu não quero que o dinheiro seja o problema entre você e o seu corpo dos sonhos.'

A OFERTA (O PULO DO GATO):

Crie uma caixa de destaque (Box) com borda pontilhada vermelha.

Texto dentro da caixa: 'LIBERAMOS UMA CONDIÇÃO ESPECIAL DE FINAL DE LOTE:'

Preço: 'De R$ 37,00 por APENAS R$ 19,90 (Pagamento Único)'.

BOTÃO CTA:

Texto: 'QUERO APROVEITAR O DESCONTO DE R$ 19,90 AGORA ➤'

Aviso abaixo do botão: '🔒 Produto 100% Digital. Acesso imediato por E-mail.'

SEÇÃO DE GARANTIA (SEGURANÇA):

Texto: 'Você ainda tem 7 dias de garantia. Se não gostar, eu devolvo seus R$ 19,90. O risco é ZERO.'

3. OTIMIZAÇÃO:

A página deve ser extremamente curta. O usuário não precisa ler tudo de novo, ele só precisa ver o desconto e o botão.

Remova o Quiz. Vá direto para a oferta.

RESUMO: Crie uma página de 'Resgate' simples, branca, com foco total no novo preço reduzido.
